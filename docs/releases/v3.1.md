# Steam Switch v3.1 正式版

v3.1 是任务栏歌词、透明任务栏、游戏存档中心和桌面图标智能隐藏完成稳定化后的首个正式版本。此版本同时包含账号切换、游戏绑定、快速启动、开机自启和底层可靠性的集中修复。

## 主要更新

- 任务栏歌词支持透明背景、专辑封面圆角、封面频谱、字体/字号、双行歌词、自适应宽度和多显示器选择。
- 存档中心支持完整/增量备份、恢复前保护、SHA-256 校验、版本保留以及完整备份导入/导出。
- 桌面图标智能隐藏支持智能、定时、手动模式，并在关闭程序或异常退出后恢复图标。
- 账号管理支持双击切换；任务栏头像右键可强制重启 Steam 并切换账号。
- 更新设置支持稳定版与测试版渠道，3.1 正式版默认稳定渠道。
- 全面统一滑动条、开关、按钮、弹窗和键盘焦点体验。

## 重要修复

- 修复歌词刷新造成整个窗口闪烁、长歌词截断和悬停控制叠字。
- 修复专辑封面裁切、任务栏底部越界和透明样式不一致。
- 修复账号筛选、排序、视图按钮以及双击切换不可用。
- 修复开机自启弹出主窗口或黑屏。
- 修复桌面图标隐藏/显示造成资源管理器刷新感，以及关闭总开关后仍可隐藏。
- 修复 WPF 静态资源缺失、动画属性路径错误和页面打开崩溃。
- 修复游戏扫描重复触发，以及绑定、存档、快速启动和账号切换中的并发与原子写入问题。
- 修复版本文字暴露 Git 提交元数据和无摘要更新无法继续的问题。
