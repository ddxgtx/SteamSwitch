## 新增

### 任务栏毛玻璃消息气泡与创意歌词灵动岛

- **专属任务栏消息气泡**：账号切换、Steam 启动/关闭等操作不再使用生硬的 Windows 系统气泡，改为在任务栏切换栏上方弹出单层流光毛玻璃胶囊气泡，配备同心圆渐变徽章、悬浮流光锚点与平滑弹性出入场动效。
- **创意任务栏歌词灵动岛与极光频谱**：封面新增双环流光光晕（`VisualizerOuterHalo` / `VisualizerAuraRing`）、玻璃微胶囊频谱徽标与彗星流光进度条；支持在设置中自由切换歌词字体（默认自动/微软雅黑 UI/霞鹜文楷/思源黑体等），并采用 `Ideal` 字形排版与灰度抗锯齿消除透明分层窗口下的文字毛边感。
- **桌面图标隐藏跨进程异常退出兜底守护**：除进程内异常钩子与下次启动恢复外，隐藏桌面图标时会自动启动极轻量后台守护进程（`--desktop-icon-guard`），即使主程序遭遇任务管理器强杀或断电崩溃，也能在检测到主进程退出后立即恢复桌面图标显示。
- **全局 UI 与排版精修**：统一主窗口、游戏存档中心悬浮操作坞（Floating Dock）、桌面快捷悬浮窗及所有自定义对话框的圆角、毛玻璃通透感与中英文字体排版。

### 账号卡片上的「切换」按钮

此前切换 Steam 身份只能靠双击卡片，界面上没有任何可见入口。现在每张账号卡片右侧都有明确的操作按钮：

- 普通账号显示「→ 切换」；
- 当前账号显示「✓ 当前」；
- 已存档账号（Steam 已裁剪、只存在于本地账号库）显示琥珀色「找回并登录」。

按钮与双击并存，共用同一套并发闸锁，行为一致。

### 侧边导航数量徽标

账号管理、游戏绑定、快捷启动三项现在会实时显示条目数量，各模块的内容规模一眼可见。

### 文案引导指向可点击的入口

账号页副标题、「我的账号」提示、已存档警示卡、游戏绑定面板提示均改为明确指出可点击的按钮（如「选中账号后点下方『保存绑定』」），不再只描述双击手势。游戏页「保存绑定」按钮新增说明：绑定后启动该游戏会自动切换到绑定账号。

## 修复

本次进行了全仓四路并行审查（核心账号与 Steam 服务、窗口与交互生命周期、设置与更新、媒体与存档），确认并修复的问题：

- **游戏列表筛选顶掉数据绑定**：筛选时给 `ItemsSource` 赋新集合，覆盖了 XAML 的 `{Binding GameList}`，导致后台扫描到的游戏永远进不了列表、绑定状态不刷新。改为 `ICollectionView` 过滤。
- **歌词岛可能永久冻结**：读取媒体属性的 WinRT 调用没有超时，一旦挂起内部标志再也不复位，歌词停在最后一帧，重启服务也无效。已加超时并在停止时复位。
- **任务栏嵌入失败被当成成功**：`SetParent` 返回值未校验就标记已嵌入，窗口实际没成为任务栏子窗口且不再重试。
- **歌词岛窗口泄漏**：重新贴靠任务栏时若已有未贴住的旧窗口，会直接新建并丢弃旧实例，其媒体轮询、定位计时器与事件订阅全部泄漏。
- **快捷启动项可能凭空消失**：配置文件读不出来时清空内存列表，随后任意一次增删又把空列表写回磁盘。现在读取失败会拒绝自动落盘并明确提示。
- **配置文件读取并发不安全**：读操作不加路径锁，且把「文件被占用」误判为「文件损坏」去回退陈旧备份，回退后的旧数据又被写回主文件。
- **设置被静默重置**：settings.json 只要有一个字段类型不对就整体判死并被默认值覆盖。现在重置前另存 `settings.json.corrupt-<时间戳>`（保留最近 5 份）。
- **开机自启被静默关闭**：读取注册表自启状态时申请的是可写句柄，受限环境下会失败并误判为未开启，进而把用户的设置改回关闭。
- **账号列表可能出现两个「当前账号」**：切换时用引用相等降级旧账号，重试路径传入刷新前的实例时会全部漏判。
- **未捕获异常弹崩溃框**：十余处 `async void` 事件处理器没有异常处理，底层 IO 一出错就弹致命错误框。统一降级为状态栏提示。
- **封面请求风暴**：取不到在线封面时每个轮询周期重试一次（约每秒 4 次），容易触发对方限流。加入 60 秒负缓存。
- **菜单无法重新固定到任务栏**：只实现了解除分支，勾选「固定」无反应。
- **托盘切换绕过并发闸锁**：托盘选账号直接发起切换，可与卡片/任务栏路径并发，两个流程同时重启 Steam。
- **周期存档备份记账过早**：先更新时间戳再执行，失败时这一轮被静默跳过，要等一整个间隔才重试。
- **存档备份不检查磁盘空间**：现在备份前预估体积并预留 20% 余量。
- **还原成功却报失败**：还原后刷新存档状态时遇到无权限目录会抛异常，盖掉「还原成功」的结果。
- 其它：图标提取异常路径泄漏 GDI 句柄、账号库字典并发访问未加锁、桌面图标恢复标记残留、酷狗歌词 BOM 未剥离、最小化到托盘时不保存窗口布局。

## 已知限制

- `mobilecdn.kugou.com` 上游不支持 HTTPS，该歌曲搜索接口仍为明文；它只传输歌曲名，不含任何凭据。
- `Hardcodet.NotifyIcon.Wpf` 仍停留在 1.1.0：2.x 为大版本升级，涉及托盘图标与菜单行为回归，需单独验证后再升级。
