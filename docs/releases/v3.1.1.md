# Steam Switch v3.1.1 正式补丁版

此版本修复 3.1 的自动更新流程。现有 3.1 用户仍需完成这一次更新；安装 3.1.1 后，后续更新将采用新的单次无感升级流程。

## 修复内容

- 点击“立即更新”后自动完成下载、SHA-256 校验、静默覆盖安装和程序重启，不再要求第二次点击“立即安装”。
- 已经下载且通过文件大小与 SHA-256 校验的安装包会直接复用，避免重试时重复下载。
- 启动安装器失败或用户取消 UAC 时保留当前程序，并显示重试入口。
- 静默安装完成后由安装器以原用户身份重新启动 Steam Switch。
- 统一手动更新与后台自动更新的安装行为。

> Windows 按计算机安装仍会显示一次系统 UAC 确认；确认后的安装与重启无需继续操作。
