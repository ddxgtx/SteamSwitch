发布日期：2026-10-19

- 安装版：`SteamSwitch-v3.2.0-win-x64-setup.exe`
- 便携版：`SteamSwitch-v3.2.0-win-x64-portable.zip`
- 校验和：`SHA256SUMS-v3.2.0.txt`

## 新增

### 本地账号库

Steam 客户端只会记住有限数量的账号，超出后会从 `loginusers.vdf` 中裁剪较早的条目，这些账号在 Steam 与本应用中都会“消失”。3.2.0 起，Steam Switch 会把扫描到的账号保存进本地账号库
（`%APPDATA%\SteamSwitch\accounts.json`），因此：

- Steam 裁剪掉的账号会继续以「已存档 · 需重新登录」状态显示在账号列表中；
- 已存档账号同样支持昵称、用户名、Steam ID 搜索，可固定到任务栏与桌面悬浮窗；
- 双击已存档账号即可切换：应用先把该账号还原写入 `loginusers.vdf`，再关闭并重启 Steam；
- 若 Steam 已不再记住该账号的密码，启动后会弹出登录框并预填账号名，登录一次后即恢复常规的免密快速切换。

> Steam Switch 不保存、也无法保存任何 Steam 密码或 Steam Guard 密钥。

## 修复

- 导入设置时的自定义 Steam 目录拒绝 UNC 与网络驱动器路径，避免从远程共享加载 `steam.exe`。
- 快速启动项执行前校验目标文件是否存在，缺失时提示而不再静默失败。
- 存档恢复写入前逐级校验符号链接，与 README 的安全声明保持一致。
- 歌词下载的 `krcs.kugou.com` 改用 HTTPS，携带 accesskey 的请求不再明文传输。
- 释放 `explorer.exe`、`notepad.exe` 等外部进程句柄。

## 改进

- 抽取 `Core/ShortcutHelper.cs`，消除账号与游戏快捷方式服务间约 100 行重复代码。
- 引入 `.editorconfig` 与 `Directory.Packages.props`，并升级 `CommunityToolkit.Mvvm` 8.4.2、`MSTest` 4.5.1、`Microsoft.NET.Test.Sdk` 18.11.0。
- 单元测试由 44 个增加到 67 个。

## 已知限制

- `mobilecdn.kugou.com` 上游不支持 HTTPS，该歌曲搜索接口仍为明文；它只传输歌曲名，不含任何凭据。
- `Hardcodet.NotifyIcon.Wpf` 仍停留在 1.1.0：2.x 为大版本升级，涉及托盘图标与菜单行为回归，需单独验证后再升级。
