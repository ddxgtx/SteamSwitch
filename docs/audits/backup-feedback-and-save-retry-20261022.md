# 备份完成反馈与设置保存恢复（2026-10-22）

本轮延续默认备份目录和设置分组，改善“保存后在哪里找”和“保存失败后如何恢复”的流程。

## 功能

- 常规设置的备份区域显示本次运行最近成功导出的文件名、类型和时间，提供“定位文件”“复制路径”。底部反馈区始终可直接定位最近备份。
- 记录使用实际导出返回路径，包含用户选择其他保存位置的情况；导出取消或失败时保留上次成功记录。记录只在本次运行有效，不写入可导入的应用配置。
- 定位/复制前检查文件是否存在；文件已移动、删除或无法访问时清除无效入口并给出明确反馈，不创建替代文件夹。
- 统一导出忙碌状态，显示保存提示，暂停重复导出及保存路径修改。主窗口与存档中心共用状态和最近记录；正在导出时不允许导入/替换应用配置。
- 设置保存失败时，在设置页头部和底部均提供立即重试入口；成功后停止重试计时器并恢复状态。
- 修复成功导入设置/应用配置后，先前的 HasSettingsSaveError 标记仍残留的问题。

实现集中在 `MainViewModel.BackupExports.cs` 和 `MainWindow.BackupExports.cs`，复用现有 BackupExportService 的目录策略及各导出器的文件验证。
