# 主界面操作提示强化（2026-10-22）

用户明确优先改善主界面。本轮强化操作入口、目标识别和反馈，不改账号切换、存档或媒体服务流程。

- 导航选中态使用更明显的蓝色背景和白色文字；账号选中卡片增加清晰描边。按钮悬停背景加强，刷新入口补充文字。
- 账号页标题与档案按钮分列，避免说明文字重叠。页面以“先选账号 → 确认目标 → 执行操作”给出直接路径。
- 区分蓝色“已选中”和绿色“当前账号”。右侧主按钮随普通目标、当前账号、归档账号分别显示切换、直接打开、找回操作，并说明可能关闭 Steam 或需要密码/验证码。无目标和忙碌时禁用主按钮。
- 账号概览收为一行，绑定游戏数按所选账号统计，不再把全库绑定数量放进单个账号详情。
- 底部反馈区加大可读字号与视觉对比，账号切换失败保留醒目的重试按钮，设置保存异常独立提示。加载时保留界面上下文，使用居中的进度卡片说明当前操作。
- 空账号列表明确提示先在 Steam 登录，并提供重新扫描按钮。列表取消固定最大高度，随工作区伸展。
- 游戏绑定页增加顺序提示，将保存与解绑并列，最小窗口下仍保留完整可选择的账号行。
- 歌词页面明确展示启用/关闭状态，将外观预览与媒体实际状态区分，移除写死的“SMTC 会话活跃”。
