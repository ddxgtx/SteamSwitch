# 默认备份导出路径与设置分组（2026-10-22）

账号库备份、应用配置包、设置导出以及游戏存档导出此前分别弹出保存文件对话框，设置页则把启动、通知、维护、窗口微调放在一条长列表中。

## 行为

- 常规设置首屏新增“备份保存位置”，可选择目录、打开目录、恢复默认。默认目录为系统“文档”下的 `SteamSwitch/Backups`。
- 默认直接保存，按照 `Accounts`、`Configuration`、`Settings`、`GameSaves` 分类；文件名包含时间与唯一标识，连续导出保留历史版本。启用“每次备份时询问保存位置”后恢复另存为流程。
- 自动导出先写同目录临时文件，成功后以禁止覆盖的方式改名；失败清理临时文件。自选路径保持各导出器对实际目标路径的校验，包括禁止账号导出覆盖本地账号库。
- 结果提示显示实际完整保存路径；无效/不可写目录报告失败，不静默切换到其他位置。切换导出目录不移动已有文件。
- 游戏存档中心的内部自动/手动备份仓库保持现有路径和恢复规则；本轮可配置目录用于用户点击的存档“导出”。页面明确说明这一范围。

## 设置页

- 常规：备份保存位置、启动行为、外观主题、通知、存档保护、游戏启动选项。
- 高级：Steam 路径与本地数据、任务栏布局、悬浮窗细节、更新、诊断和配置导入导出。
- 页签切换保留配置和各自滚动位置，现有命名控件和事件处理器保留；顶部显示保存中、自动保存或保存失败状态。
- 路径规则集中在 `BackupExportService`，页签样式集中在 `Resources/SettingsStyles.xaml`。新增字段通过 AppSettings、SettingsSession 和 MainViewModel.Settings 统一保存及导入应用，避免每个导出入口独立维护路径。
