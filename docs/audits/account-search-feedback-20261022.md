# 多账号库搜索与筛选反馈（2026-10-22）

本轮延续多账号库功能，改善账号数量较多时的查找和空列表反馈。

- 列表标题下显示当前结果数量和本地收录总数；搜索时同时说明当前筛选范围。
- 搜索框增加清除按钮，支持 Ctrl+F 定位搜索、Esc 清除搜索。清除保留当前筛选；“查看全部”及空状态按钮清除搜索和筛选。
- 新账号库、搜索无匹配、筛选无结果分别提供引导；未收录时直接提供收录按钮，有账号时提供恢复全部列表的按钮。
- 使用 WPF live filtering / sorting 跟随固定和当前账号状态，固定优先排序随星标变化更新。结果集合改变时更新数量并清除不再可见的选择，避免右侧继续操作隐藏账号。
- 更正账号卡片和详情中的登录名标签，避免与数字 Steam ID 混淆。
- 新增 MainWindow.AccountLibrary.cs 集中处理反馈、快捷键和集合订阅，退出时解除订阅。结果数量优先读取 CollectionView.Count，避免每次逐项遍历。
