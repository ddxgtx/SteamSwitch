v3.0

全新界面，更清晰的账号与游戏工作流

重构四个核心页面，游戏直接显示启动账号；修复开机自启 UAC 冲突，并完善悬浮窗、任务栏常驻窗与后台任务的资源释放。

功能特性

为 Steam 多账号用户打造的高效管理工具

🎮

账号切换

自动读取本机 Steam 账号，一键切换并启动，支持系统托盘和无密码桌面快捷方式

🔗

游戏绑定

扫描本机已安装游戏，为每个游戏绑定默认启动账号，支持程序快速启动和快捷入口一键启动

💾

游戏存档中心

按账号检查 userdata 或自定义目录，支持 Steam 退出后自动备份、变化预览和去重，并可从保护版本安全恢复

📌

任务栏常驻

将账号和游戏嵌入 Windows 任务栏，支持液态玻璃效果、圆角模式、位置调节

🎵

任务栏歌词

在账号切换区左侧显示同步歌词，并直接控制上一首、播放/暂停和下一首；支持系统媒体会话与可选 LRCLIB 在线歌词；播放视频等其他媒体时自动隐藏。

🪟

桌面悬浮窗

可拖动的快捷入口，支持 6 种玻璃颜色、透明度调节、始终置顶，不出现在 Alt+Tab

💉

Steam 库注入

在游戏详情页注入「切换启动」按钮，点击直接使用绑定账号启动游戏

🔄

自动更新

启动时自动检查 GitHub 最新版本，发现新版本弹窗提示，支持一键下载安装

🎨

主题切换

暗黑模式与白色模式一键切换，所有界面元素跟随主题自动变化

⚙️

独立设置

任务栏与悬浮窗完全独立配置，窗口大小、图标大小、效果均可分别调节

🛡️

安全稳定

不保存 Steam 密码、不注入游戏进程；账号凭据继续由 Steam 管理，程序本体无需管理员权限

可选功能提示：Steam 库界面注入默认关闭，启用后会开启本地 CEF 调试端口。账号切换、游戏绑定和快捷入口无需开启该功能。
